Error Detection & Data Reliability

Understanding Even Parity, Transmission Errors, and System Response

Learning Target Add & check even-parity bits, detect errors, & explain parity limits.

Guided Notes — Reliability & Parity

Data Corruption

A stored or transmitted bit pattern changes from the original (e.g. 0 becomes 1).

Redundancy

Extra information added to data to help verify accuracy and detect errors.

Parity Bit

An extra bit appended so the total number of 1s satisfies a designated rule.

Even Parity

The final transmitted bit pattern MUST contain an EVEN number of total 1s.

Error Detection

Recognizing that transmitted data has been corrupted. Note: Detecting an error is not the same as correcting it!
