Part 1

Guided Notes: Flowcharts

Symbol Reference

A flowchart is a visual way to show the steps and paths in an algorithm. Match or review each standard symbol shape with its meaning and function.

Symbol / Shape Meaning What it tells us
Oval Start / End Where the algorithm begins or finishes.
Rect Process / Action A step or action to complete.
Diam Decision A question that creates different paths.
Arrow Direction / Sequence Which step comes next.

Part 3

Pseudocode

Logic & Syntax
Sample Pseudocode Structure
START
Wake up
Get dressed
Eat breakfast
IF backpack is ready
Leave for school
ELSE
Get backpack
Leave for school
END

Translate It!

Turn this everyday process into structured pseudocode: Wash your hands before lunch. Include at least 5 to 6 steps.

Day 4 Key Ideas

  • Flowcharts use standard symbols and arrows to show an algorithm visually.
  • Pseudocode uses simple, structured written language to show logic.
  • A decision (diamond / IF-ELSE) creates more than one possible path.
  • Testing & debugging help catch errors and improve algorithm clarity.
