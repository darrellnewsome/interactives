Part 3

File Naming – Good vs. Bad Examples

Here is a common mistake made in school: naming files something like project1-final-FINAL-reallyfinal.docx 😬

The 3 Essential Questions Every File Name Must Answer:

1
Which Unit? e.g., Unit2
2
What is it? e.g., InternetSafety
3
Whose file? e.g., JohnD
❌ Bad Example Confusing
myproject.pptx
  • ❌ Doesn't tell you which class or unit it is for.
  • ❌ Doesn't tell the teacher who created it.
  • ❌ Hard to find when searching later.
✅ Good Example Self-Descriptive
Unit2 _ InternetSafety _ JohnD .pptx
  • Unit2 = Answers Which Unit?
  • InternetSafety = Answers What topic?
  • JohnD = Answers Whose file?
