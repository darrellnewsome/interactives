Guided Notes — Coding Basics

Hover or tap cards to review!

Program

A set of instructions a computer follows.

Command

One instruction in a program.

Sequence

Commands arranged in the order they should happen.

Event

Something that starts or triggers an action in a program.

Sprite / Object

A character or item that can be controlled in a program.
